# DEC-015: v1 Does Not Change What Explore and Apply Load

## Question

The point of compaction is that agents load the compacted surrogate instead of the full driver-specs and ADRs. Should this initiative make that switch?

## Decision

No. v1 produces the views, the manifest, `--check` and the open-loop backlog. It does not change what `/opsp:explore` or `/opsp:apply` load.

The switch is a later initiative, taken once the views have been proven against real work on a mature surrogate.

## Consideration Factors

| Factor | Weight | Defer the switch | Switch in v1 |
|---|---|---|---|
| Risk if views are wrong | HIGH | Records still ground every operation ✓ | Every downstream agent operation degrades ✗ |
| Evidence available | HIGH | Views can be compared against real initiative work first ✓ | No evidence yet that a view answers what apply asks ✗ |
| Delivers the token win | HIGH | Deferred ✗ | Immediate ✓ |
| Guardrail conflict | MED | None ✓ | Overrides apply's "ALWAYS retain full surrogate context" ✗ |

## Rationale

Switching the read path makes the view the effective surrogate, and nothing then cross-checks it. That is the asymmetry [[DEC-002]] records for reconciliation: a deferred win costs time, a wrong surrogate costs every decision made against it. Staging is a gate, not an environment — the views must be validated before anything depends on them.

Two things make the deferral cheap. The hat partition does not deliver the token win on its own — measured against cashier's initiatives, four of six span all four hats, so an agent will load every view and the saving comes from condensation rather than from skipping hats. And the governance value — ownership, escalation routing, the open-loop backlog — lands in v1 without the switch.

When the switch comes, the rule should be: **use the view to find your way, read the record before acting on it** ([[DEC-009]]).

## Invalidation Trigger

Once the views have been compiled against a mature surrogate and compared with the records an initiative actually needed, this decision should be revisited — that comparison is the evidence it is waiting for.
