# DEC-002: Conflict Resolution Policy — Agent Reasons, Operator Confirms

## Question

When two universes diverge in their surrogates, how should conflicts be resolved?

## Decision

The agent reasons through conflicts and proposes resolutions, but auto-accepts only under two narrow conditions:
1. **Purely additive**: one universe has content the other lacks, with no semantic overlap
2. **Identical**: both universes have identical content (trivially redundant)

All other cases — including "similar but not identical" — escalate to the operator. The agent should express uncertainty liberally.

## Consideration Factors

- **Blast radius asymmetry**: a false escalation costs one operator confirmation prompt; a false auto-accept risks a corrupted surrogate that degrades all downstream agent operations
- **Semantic conflicts**: ADR contradictions are not text conflicts — they require understanding intent, not just diffing lines
- **Extended thinking**: complex surrogate conflicts benefit from the most capable available model reasoning through the implications before presenting options to the operator

## Rationale

Treating the surrogate like code and applying "auto-merge when clean" semantics is insufficient. Two ADRs can differ by one sentence but represent fundamentally incompatible worldviews. The bias toward escalation is intentional and should be considered a feature, not a limitation.

## Invalidation Trigger

If escalation rate proves too high in practice (operator fatigue), a confidence-scoring rubric can be introduced to tune the threshold — but the default should always remain conservative.
